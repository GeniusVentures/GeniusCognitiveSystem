Service contract (Plan 02) — the only rules the adapter may call:

```
JoinOutcome JoinTopic(const std::string &);
DerivedJoinResult RefreshDerivedJoins();   // {registered, failed}; never invokes the sink
std::vector<std::string> JoinedTopics() const;
bool IsJoined(std::string_view) const;
std::optional<std::string> SendTextDenial(std::string_view) const;
std::optional<std::string> CreateRoomDenial(std::string_view) const;
std::optional<std::string> UpdateSpaceDenial(std::string_view) const;
static SmokeJoinResult RegisterSmokeTopics(CoreSession &);
static bool IsTopicTooLong(std::string_view);
static bool IsValidTopicShape(std::string_view);
static std::string RoomIdFromTopic(std::string_view);
static std::string TopicForRoomId(std::string_view);
```

Lock contract: `JoinTopic` may be called only with `g_mutex` released (its sink takes `g_mutex`); the service releases its own mutex before invoking the sink. `RefreshDerivedJoins` may be called with `g_mutex` held (it calls EntityStore/Membership/CoreSession registration, never the sink). `g_inFlight` brackets every unlocked `JoinTopic` call.
