<objective>
Build the testable C++ messaging component — with the D-08 injected crypto seam and the stateless OpenSSL adapter behind it — that turns Phase 1's local echo into the real encrypted P2P send/receive/history path, and prove it with C++ tests.

Purpose: D-03: raw full-value GossipSub `Publish` on the room topic for LIVE delivery + topics-aware `Put` for the CRDT archive; apply-once dedupe keyed by id funnels BOTH the live subscribe handler and the `RegisterNewElementCallback` CRDT heal path; `PutLocal` no-rebroadcast. D-01: (timestamp, id) total sort over the converged prefix scan. D-04: sender stamped by C++, never from Dart. D-06: `QueryHistory` builds the sorted `MessageHistory` batch that join replay pushes. D-07: pending -> complete/error lifecycle. D-08: the serialized record is encrypted WHOLE before BOTH the live `Publish` and the archive `Put` (envelope = nonce(12) || ciphertext || tag(16)), decrypted only inside the Messaging layer (`ApplyMessage` funnel and `QueryHistory` scan) BEFORE parse/dedupe/sort; decrypt failure = skip-and-log (same posture as unparseable); storage stays opaque-bytes and `Messaging` NEVER calls OpenSSL directly — encryption lives behind an injected `CryptoSeam` (callable pair + enabled flag), so when encryption is not enabled the functions are simply not called and payloads flow as plaintext (one component, two paths, both testable this phase).

Output: `gcs_crypto.{hpp,cpp}` (new), `gcs_messaging.{hpp,cpp}` (new), `test_gcs_crypto.cpp` + `test_gcs_messaging.cpp` (new), CMake registrations (including the `OpenSSL::Crypto` link line).

Coverage boundary (SC2/SC3): live cross-peer delivery (SC2) and two-live-session convergence (SC3) require two simultaneously-running GossipSub nodes with peer discovery; the Tier-2 injected-pubsub fixture binds a single host to port 0 with no peer discovery, so those two success criteria are human-verified in 03-06 (two live app instances). namespace gcs {
class Messaging {
public:
  using EventSink = std::function<void(const chat::GcsEvent &)>;
  using EncryptFn = std::function<outcome::result<std::string>(
      const std::string &roomTopic, const std::string &plaintext)>;
  using DecryptFn = std::function<outcome::result<std::string>(
      const std::string &roomTopic, const std::string &envelope)>;

  struct CryptoSeam {              // D-08 injected seam — injectable per Messaging instance
    EncryptFn encrypt = nullptr;  // production: gcs::crypto::EncryptPayload; tests: real adapter or counting stubs
    DecryptFn decrypt = nullptr;
    bool enabled = false;         // disabled (or empty callables) = plaintext path: functions simply not called
  };

  static constexpr const char *kMessagesKeyPrefix = "gcs/messages/";

  explicit Messaging(CoreSession &session, std::string senderAddress, EventSink sink,
                     CryptoSeam crypto = {});

  bool EncryptionEnabled() const;

  outcome::result<void> SendMessage(const std::string &roomTopic, const std::string &text);
  void OnLiveMessage(const std::string &topic, const std::string &valueBytes);   // D-03 raw GossipSub live path
  void OnMessageArrived(const std::string &key, const std::string &valueBytes);  // D-03 CRDT heal path
  outcome::result<chat::MessageHistory> QueryHistory(const std::string &roomTopic);

private:
  std::string NextMessageId();
  static std::string BuildKey(const std::string &roomTopic, const std::string &id); // "gcs/messages/" + roomTopic + "/" + id
  static std::string RoomTopicFromKey(const std::string &key); // strips kMessagesKeyPrefix + trailing "/<id>" (topics may contain '/')
  void ApplyMessage(const std::string &roomTopic, const std::string &valueBytes);
    // single funnel: decrypt (if enabled; skip-and-log on failure) -> parse (skip-and-log) ->
    // dedupe(id) -> PushMessage -> PutLocal(envelope AS RECEIVED, never the plaintext)
  void PushMessage(const chat::ChatMessageState &msg); // role flip (self vs peer) + sink (plaintext only)
  static chat::MessageRole RoleFor(const chat::ChatMessageState &msg,
                                   const std::string &sender); // USER_SELF iff msg.sender()==sender else USER_PEER
  CoreSession &m_session;
  std::string m_sender;                                   // injected: FFI passes GeniusSDKGetAddress().address; tests pass a fixed string
  EventSink m_sink;
  CryptoSeam m_crypto;                                    // D-08 seam (Messaging never includes <openssl/*>)
  bool m_encryptionEnabled;                               // crypto.enabled && crypto.encrypt && crypto.decrypt
  std::unordered_set<std::string> m_seenIds;              // apply-once dedupe, bounded by kMaxSeenIds — LOAD-BEARING: every message arrives twice (live + CRDT)
};
}
