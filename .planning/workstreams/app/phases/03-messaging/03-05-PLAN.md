<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Dart -> gcs_publish -> send_text/join_topic | Untrusted command bytes parse into command envelopes; room_topic/text are the hostile inputs |
| CRDT io thread + GossipSub strand -> receive callbacks | Remote message envelopes cross into FFI session state (mutex discipline); decryption stays inside Messaging |
| production composition | gcs_init must construct the encrypted production path — a mis-wired seam would silently run plaintext |

| T-03-13 | DoS | oversized publish | mitigate | `kMaxMessageTextLength` (4096) and `kMaxTopicLength` (128) bound the serialized payload (envelope adds a fixed 28 bytes). |
