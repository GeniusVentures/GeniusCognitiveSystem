    Strict rules: no void* DI; typed interface references; no polling loops (ReceivePort listener only);

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| NativePort payload -> SessionCubit | Untrusted C++-originated protobuf bytes decoded into GcsEvent |
| GcsEvent -> ChatFlowItem text | Decoded message text flows into widget rendering |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-11-01 | Tampering | GcsEvent.fromBuffer decode | mitigate | Generated protobuf decode validates tags/limits; malformed bytes throw a parse error (caught/logged), never crash. |
| T-01-11-02 | Injection | message text -> widget text | mitigate | Payload flows into a Text widget (no HTML/markup eval); no raw HTML rendering. |
| T-01-11-03 | DoS | unbounded ChatFlowItem list | mitigate | MessageFlowCubit caps list length (constexpr kMaxFlowItems) dropping oldest. |
| T-01-11-04 | Elevation of Privilege | FFI handle misuse | mitigate | SessionCubit owns the handle exclusively; close() idempotent; no raw handle exposure to widgets. |
| T-01-11-05 | Info Disclosure | room topics list | accept | Phase 1 room list is the pushed smoke-topic set; no sensitive data. |
| T-01-11-SC | Tampering | package installs | accept | No npm/pip/cargo installs (dart pub out of scope). |
</threat_model>
