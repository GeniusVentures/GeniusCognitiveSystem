C-side typed-data posting shape (protobuf bytes, D-26):
```c
std::string bytes = event.SerializeAsString();
Dart_CObject message;
message.type = Dart_CObject_kTypedData;
message.value.as_typed_data.type = Dart_TypedData_kUint8;
message.value.as_typed_data.length = (intptr_t)bytes.size();
message.value.as_typed_data.values = reinterpret_cast<uint8_t*>(const_cast<char*>(bytes.data()));
Dart_PostCObject(port, &message);   // Dart VM copies synchronously; bytes alive through this call
```

Dart-side receive + decode shape:
```dart
final receivePort = ReceivePort();
bindings.gcs_subscribe(handle, 'gcs/event'.toNativeUtf8(), receivePort.sendPort.nativePort);
receivePort.listen((msg) {
  final bytes = msg as Uint8List;                 // posted typed-data arrives as Uint8List
  final event = GcsEvent.fromBuffer(bytes);        // package:protobuf decode
  // event.hasRoomList() / event.hasReadiness() / event.hasMessage() / event.hasError() dispatch
});
```

Dart-side command publish shape (D-27: commands are topic publishes; D-29: codec-tagged bytes).
Caller owns the buffer for the call duration — allocate, call, free:
```dart
final command = GcsCommand()
  ..sendText = (SendTextCommand()
    ..roomTopic = 'gcs/chat/smoke-test'
    ..text = 'hello-from-dart');
final bytes = command.writeToBuffer();
final ptr = calloc<Uint8>(bytes.length);
ptr.asTypedList(bytes.length).setAll(0, bytes);
final status = bindings.gcs_publish(handle, 'gcs/command'.toNativeUtf8(), ptr, bytes.length);
calloc.free(ptr);
```

Dart-side init shape (D-29: GcsConfig bytes, codec bound per store at creation):
```dart
final config = GcsConfig()
  ..dbPath = tempDbPath
  ..codec = Codec.CODEC_PROTOBUF;
final bytes = config.writeToBuffer();
final ptr = calloc<Uint8>(bytes.length);
ptr.asTypedList(bytes.length).setAll(0, bytes);
final handle = bindings.gcs_init(ptr, bytes.length);
calloc.free(ptr);
```

ffigen mapping: int64_t <-> Dart int, GcsSession* <-> Pointer<GcsSession> (opaque struct).

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05-01 | Tampering | g_dartPort lifetime | mitigate | gcs_shutdown zeroes g_dartPort BEFORE g_session teardown (unregister-before-free); PostToDart ignores a closed-port result. |
| T-01-05-02 | Tampering | Dart_CObject buffer ownership | mitigate | PostToDart posts a stack-local std::string whose lifetime covers the synchronous Dart_PostCObject call (Dart VM copies before return); no dangling heap buffer. |
| T-01-05-03 | Tampering | protobuf decode of pushed bytes | mitigate | Dart decodes with generated protobuf (tag/limit validation); malformed bytes surface as a parse error, not memory corruption. |
| T-01-05-04 | Denial of Service | gcs_publish echo loop | accept | Phase 1 echo is a single round-trip per publish; no fan-out. |
| T-01-05-05 | Elevation of Privilege | gcs_subscribe register | mitigate | gcs_subscribe validates session handle matches g_session and rejects dartPort 0 before storing the port. |
| T-01-05-06 | Tampering | Dart-side publish/init buffers | mitigate | Dart owns its malloc'd byte buffers for the synchronous call duration only (allocate → copy → call → free); C++ copies inbound bytes inside the call — no dangling pointer window on either side. |
| T-01-05-SC | Tampering | package installs | accept | No npm/pip/cargo installs (Dart pub deps are not in scope of the npm/pip/cargo gate). |
