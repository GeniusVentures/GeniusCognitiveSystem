## Interfaces the executor needs

From `GeniusSigner.hpp` (authoritative; argument order included):

```cpp
static GeniusSigner Generate();                                   // BY VALUE
[[nodiscard]] std::string GetAddress() const;                     // bare 128 hex
[[nodiscard]] std::vector<uint8_t> Sign( const std::vector<uint8_t> &data ) const;
static bool VerifySignature( const std::string          &address,
                             std::string_view            signature,
                             const std::vector<uint8_t> &data );
static bool VerifySignature( const std::string          &address,
                             const std::vector<uint8_t> &signature,
                             const std::vector<uint8_t> &data );
```

Slot 2 is the signature, slot 3 is the data. Use the byte-vector overload. `base::unhex` needs a BARE 128-hex address; strip a leading `"0x"`.

From `src/lib/gcs_membership.hpp` (04-15): `KeyWrapSeam::sign` is `( payload, issuer ) -> raw 64 bytes as std::string`; `verifyIssuer` is `( issuer, payload, signature ) -> outcome::result<bool>`. The seam order and the signer order differ — the adapter reorders.

From `src/lib/gcs_crypto.hpp` (04-15): `HexEncode`/`HexDecode` are public; `MintInviteAuthenticator`/`VerifyInviteAuthenticator` keep their existing signatures.

From `test/test_gcs_invite_helpers.hpp` (created by 04-15): `gcs::test::BuildInviteIssuerPayload( inviteId, record )` — the single canonical payload builder. Include it; never re-implement the payload in this file.

From `src/lib/gcs_membership.hpp`: `kInvitesKeyPrefix` and `kMembersKeyPrefix` are PUBLIC; `InviteKey`/`MemberKey` are PRIVATE. Build every test key from the public prefixes.
