<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CRDT store (RocksDB) → EntityStore | Persisted record bytes are re-read at startup; if the DB were tampered with, hostile bytes cross here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering / DoS | EntityStore::LoadFromStore record/manifest parse | mitigate | ParseFromString failure on any record ⇒ spdlog::warn + skip that id, never abort startup; manifest Get failure ⇒ empty catalog |
| T-02-02 | Tampering | EntityStore::NextEntityId | mitigate | seed+counter id minting (wall-clock ms + random_device + atomic seq, CR-01); entity tests assert the salt-separator shape, so a bare-counter revert fails |
| T-02-03 | DoS | unbounded manifest id list | accept | local single-user store at Phase 2 scale (tens of entities); N+1 reads are the documented accepted v1 tradeoff |
| T-02-SC | Tampering | package installs | accept | zero new packages this phase (02-RESEARCH Package Legitimacy Audit) — slopcheck gate not applicable |
</threat_model>
