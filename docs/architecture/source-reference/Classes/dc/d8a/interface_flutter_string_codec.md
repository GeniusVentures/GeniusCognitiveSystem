## Detailed Description


A [`FlutterMessageCodec`] using UTF-8 encoded `NSString` messages.

This codec is guaranteed to be compatible with the corresponding [StringCodec](https://api.flutter.dev/flutter/services/StringCodec-class.html) on the Dart side. These parts of the Flutter SDK are evolved synchronously.
