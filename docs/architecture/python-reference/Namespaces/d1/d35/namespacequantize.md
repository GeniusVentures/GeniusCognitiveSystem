GNUS-POC quantization — FP4 binary export for C++ engine.

Provides:
- FP4Exporter: SGFP4 v1 fixed 64x64 and v2 adaptive quadtree export

- LaplacianWeightedError: encode-side Laplacian pyramid error analysis
